并发数：阅读APP同时发起的语音合成请求数量。数值越大，预缓冲的语音段落越多，可吸收 LLM 预处理延迟，但也会增加瞬时 API 调用并发量。可在阅读APP的朗读引擎设置中调整。

LLM 文本预处理

在 TTS 合成前调用 MiniMax LLM 净化文本：删除 Markdown 符号、表情、动作括注，合并连续标点等。需额外计入 token 成本。设置全局生效，不随配置切换。

高速版成本低，适合短文本净化
